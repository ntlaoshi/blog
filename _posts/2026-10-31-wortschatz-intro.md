## 一、为什么做这个 App

背德语单词有一个绕不开的难点：**名词必须同时记住词性和复数**。

德语名词有三个性（der / die / das），复数变化几乎没有规律——

- der Mann → die Männer（变音 + er）
- die Frau → die Frauen（加 en）
- das Mädchen → die Mädchen（不变）
- der Bus → die Busse（s 变 ss）

只背「Mann = 男人」是不够的，还必须同时记住「der」和「Männer」，否则既说不出一句完整的话，也听不懂变格后的形式。

市面上的背单词软件大多把单词当孤立词条处理，名词的性和复数常常缺位。于是决定自己做一个，核心诉求很明确：

1. **名词带性别和复数**，正面看得到，反面记得住；
2. **离线可用**，发音内置，飞行模式也能正常背；
3. **轻量**，一个安装包搞定，不依赖服务器。

## 二、开发思路

### 1. 词库：人工精编 + 中文维基词典

词库是这类 App 的地基。当前约 **10313 词**，由两部分合成：

| 来源 | 条数 | 特点 |
|---|---|---|
| 人工精编 | 1616 | 含例句、英文对照、主题标签，性别与复数经人工校订 |
| 中文维基词典 | 8697 | 释义为社区人工编纂，简体化后入库；性别与复数取自英文维基词典数据 |

**精编部分**负责质量：每个词都配了例句和中文翻译，名词的性别、复数逐条核对。这部分用来支撑高频、基础词的学习体验。

**维基部分**负责规模：中文维基词典的德语释义覆盖率高达 **99.7%**，且是人工编纂而非机器翻译，把它作为扩充来源能快速把词量做到上万。

这里有一个重要的数据源取舍。曾评估过用 FreeDict 的「德→英→中」组合自动构建，抽样两万条后果断放弃——中文覆盖率只有 18.4%，而且二次转译会逐层放大错误：`Aasfresser`（食腐动物）被译成「跳水员」，`Aas fressen` 被译成「洗涤」。机器二次转译的误差在长尾词上完全不可控，这是自动构建路线的根本缺陷。

维基词条的筛选规则也很关键：

- 只保留德语词频表前 22000 名的词；
- 丢弃 `form-of` 变位条目（如把 `red` 当作独立词条收录）；
- 名词若无性别则不入库——缺冠词的德语名词无法使用。

### 2. 发音：离线神经网络语音

背单词必须能听发音，但离线应用不能依赖系统 TTS 组件（不同厂商、不同系统版本差异太大）。

做法是：用微软 Edge 的神经网络语音 `de-DE-KatjaNeural` **离线批量合成** MP3，随 App 打包内置。这样发音质量接近真人、又完全离线，飞行模式下照常可读。低频词没有内置音频时再联网获取，取不到就明确提示，而不是静默失败。

### 3. 学习算法：SM-2 管长期，连对三次管当轮

背单词的调度分两个层面：

**长期层面**用经典的 SM-2 间隔重复算法，决定每个词「下次什么时候复习」。评分映射到记忆难度，间隔按记忆表现指数增长。

**当轮层面**则更严格：一轮学习里，一个词要**连续认识 3 次**才算通过。中途评一次「模糊」或「忘了」，计数直接清零，词条被随机插回队列稍后重判。没达标的词不会进入本轮的完成统计，也不会进入拼写测试。

这个设计解决了一个常见问题：很多软件「点一下就过」，用户其实没记住。连对三次的门槛让「点过去」变得困难，又不会像死记硬背那样低效。

### 4. 拼写：拼对才算过

学完一轮进入拼写自测，看中文写德语。这里的规则同样是「拼对才算通过」：

- 拼错 → 当场显示正确答案，该词排到队尾，等其余词测完再回来重测，直到拼对；
- 全部拼对才进入结果页，结果页显示「第一次就拼对的词数 / 总数」，比一个必然满分的「正确率」更有信息量。

德语变音字母（ä ö ü ß）在多数手机键盘上打不出来，所以判定时 `ä=ae`、`ö=oe`、`ü=ue`、`ß=ss` 双向等价，输入框下方也放了四个可点的变音字母按键。

### 5. 交互：卡片手势 + 进度可视化

背单词的主体是一张可滑动的卡片：

- **左滑**认识、**右滑**忘了、**上滑**模糊、**下滑**收藏；
- 卡片顶部三个圆点显示「连续认识 n/3」；
- 名词复数的显示支持两种方式：完整形式（`die Männer`）或教材式词尾（`¨-er`），可随时切换。

「已掌握」按钮放在卡片右下角，单手握持时拇指更容易点到，点击后该词永久退出复习队列。

## 三、用法

### 安装

从 GitHub Release 下载 APK 直接安装（Android 8.0+，minSdk 26）。

### 背单词

首页点击「学新词」或「开始复习」，进入卡片学习：

1. 正面显示德语单词 + 名词复数，轻触卡片翻面看释义；
2. 用底部按钮或滑动手势评分；
3. 每词连续认识 3 次算过；
4. 学完一轮进入拼写自测，拼对才通过；
5. 想永久跳过某个词，点右下角「已掌握」。

### 查词

底部「查词」页支持德语和中文双向检索，前缀匹配优先、完全匹配置顶。本地查不到时可走在线翻译兜底，并一键存入词库。空查询时会显示「最近查过」的历史记录。

### 收藏

任意词条可点星收藏，集中在「收藏」页回看；背单词时下滑卡片也能直接收藏。

### 导入自己的单词书

在「设置 → 词库 → 导入词表」里导入 JSON 文件。最小格式只需两个字段：

```json
{ "words": [ { "w": "der Hund", "zh": "狗" } ] }
```

导入后自动新建一本同名单词书，学习范围随之切换；按词形去重，重复导入不会产生重复条目。

### 常用设置

- **学习等级开关**：A1–B2 自由勾选；
- **每轮词数**：5–100；
- **自动朗读 / 语速**：0.5x–1.3x；
- **名词复数显示**：完整形式 / 教材式词尾；
- **拼写自测**：可开可关。

## 四、技术栈

- Kotlin 2.0 + Jetpack Compose（Material 3）
- 原生 SQLite（不引入 Room，避免注解处理器依赖，构建更快）
- 无第三方网络库：在线兜底用 `HttpURLConnection` + 内置 `org.json`
- 单体 ViewModel 管理状态与业务编排，UI 按页面拆分

整个项目刻意保持轻依赖，一个 APK 即可运行，数据全部落在本地。
