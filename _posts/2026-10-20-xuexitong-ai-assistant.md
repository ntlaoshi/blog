## 项目简介

**学习通全自动助手**是一个跑在浏览器里的学习辅助脚本（需要 **脚本猫 ScriptCat** 或 Tampermonkey），面向「超星学习通 / 学银在线」的课程页面，把重复操作自动化掉：

- 视频自动播放、防暂停、后台保活
- 章节测验自动识别题目、调用模型作答、自动提交
- 文档 / PPT 自动阅读后进入下一节
- 直播、作业、考试：实验性支持
- 一键循环「视频 → 测验 → 下一节」，自动跳过已完成任务

它最大的特点是：**不依赖任何第三方付费题库**，答题可以走本机大模型，也可以走你自己的 API。

## 两种答题方式

### 本地模型（免费、数据不出本机）

用 [Ollama](https://ollama.com) 在本机跑一个模型：

```bash
ollama pull qwen2.5:7b
ollama serve
```

面板选「本地模型」，默认接口是 `http://localhost:11434/v1/chat/completions`。

适合有独立显卡、或者不想把题目发到外面的场景；缺点是推理速度取决于本机配置。

### 远程 API（不挑电脑配置）

面板切到「API」，填三项：

| 配置项 | 说明 |
| --- | --- |
| API 地址 | 任意 OpenAI 兼容接口 |
| API Key | 你的密钥 |
| 模型名 | 例如 `deepseek-chat`、`gpt-4o-mini` |

脚本内置了常见服务商的下拉选择：

- DeepSeek
- OpenAI
- 通义千问（阿里云百炼）
- 硅基流动
- Moonshot（Kimi）
- 智谱 GLM
- 自定义任意 OpenAI 兼容地址

选中服务商会自动填好接口地址；**填入 Key 后约 0.8 秒自动拉取模型列表**，直接选一个即可，也可以手动输入模型名。

## 面板与开关

- 面板只在**课程首页 / 章节列表页**出现，播放页不显示，这是正常设计。
- 顶部「答题方式」两个按钮：绿色是当前选中，红色是未选中，点一下切换。
- 任务开关统一配色：**绿色开、红色关**。
- 连接状态实时显示：本地模型显示是否连上 Ollama，API 显示是否已配置；每 30 秒刷新一次，也可以手动「重新检测」。
- 即使 Ollama 没启动，也会在 6 秒内明确显示未连接，不会一直卡在「检测中」。

2. 把 `xuexitong-assistant-local.user.js` 拖进脚本猫，确认安装并启用；
3. 打开学习通课程首页，面板会自动出现。

## 使用流程

1. 进入课程首页或章节列表页；
2. 选择答题方式（本地模型 / API），完成配置；
3. 点「测试模型」或「重新检测」，确认连接正常；
4. 按需打开任务开关；
5. 点「开始刷课」，脚本自动循环执行。

## 常见问题

**Q：面板不出现？**
确认当前是课程首页或章节列表页；播放页、个人中心等页面不显示面板。

**Q：选了 API，模型列表加载不出来？**
检查 Key 是否有效、该服务商是否支持 `/models` 接口、网络是否可达；也可以手动输入模型名。

**Q：本地模型一直显示未连接？**
先确认 Ollama 已启动（端口 11434 可访问），再点「重新检测」；仍不行就重启 Ollama 服务。

**Q：点了按钮没反应？**
确认安装的是最新版本，并对页面执行 `Ctrl+F5` 强制刷新。
