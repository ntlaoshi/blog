## 安装步骤

### 1. 安装脚本管理器

浏览器安装 **脚本猫（ScriptCat）** 扩展（Edge / Chrome 均可）。

### 2. 安装脚本

把 `xuexitong-jiujiu-local.user.js` 拖进脚本猫，确认安装并启用。

### 3. 准备本地模型（答题必需）

安装 [Ollama](https://ollama.com)，然后拉取一个模型：

```bash
ollama pull qwen2.5:7b
```

启动服务：

```bash
ollama serve
```

默认接口地址为 `http://localhost:11434/v1/chat/completions`。

### 4. 开始使用

进入学习通课程播放页（地址包含 `studentstudy`），脚本面板会自动出现，然后：

1. 在面板里填写模型地址和模型名；
2. 点「测试模型」确认连接正常；
3. 点「开始刷课」，脚本就会自动运行。

## 常见问题

**Q：脚本不自动播放？**  
检查当前是否在学习通**播放页**（地址含 `studentstudy`），而不是课程首页。

**Q：答题提示连接失败？**  
确认 Ollama 已启动（端口 11434 可访问），面板里的地址和模型名与实际一致。

**Q：切到后台就暂停？**  
在 Edge 设置（`edge://settings/system`）中关闭「睡眠标签页」。

**Q：某些任务被跳过？**  
脚本会自动跳过已完成的章节；若某个任务类型不需要处理，可在面板里关闭对应开关。
